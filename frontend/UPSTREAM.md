# Vendored UI foundation

AutoStock's React frontend uses selected components and configuration patterns
from [satnaing/shadcn-admin](https://github.com/satnaing/shadcn-admin), commit
`e16c87f213a5ba5e45964e9b67c792105ec74d26` (MIT licensed). The copyright and
MIT license notice are preserved in
[`LICENSES/satnaing-shadcn-admin-MIT.txt`](LICENSES/satnaing-shadcn-admin-MIT.txt).

The responsive sidebar and Shadcn/Radix primitives in `src/components/ui/`,
the `cn` utility, and mobile-sidebar hook are adapted from that source. Its demo
business pages, mock records, Clerk examples, user/task management, and unrelated
settings pages were not copied. AutoStock owns its Odoo session, API contracts,
dashboard data presentation, and visual tokens.
